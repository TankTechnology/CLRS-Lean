**31-MR-WORK (confirmed MAJOR).** At 2075–2076, the Boolean is `millerRabin n a && pass`, where `millerRabin` is `decide (strongPseudoprime n a)` at 218–219. That predicate at 197–200 computes congruences of ordinary powers `a^d` and `a^(2^i*d)` after obtaining `s,d` through `Nat.factorization`. Independently, the cost field adds `(modExpWithCount a n (n−1)).2`; its computed residue is never consumed by the Boolean test. The proof at 2089 merely sums the standalone modExp bound. Thus replacing the Boolean test by any far more expensive procedure with the same answer would leave the purported runtime bound intact. This is not an allocation or RAM exclusion: the charged modular multiplication execution does not compute the represented test at all. The guide explicitly calls this the “underlying repeated squarings” and says “Deferred: none.” Fix: implement a single-base witnessed repeated-squaring execution with result/count in one record, prove result equals `millerRabin`, and compose that record in the multi-base loop; bound parameter decomposition separately. Preserve the existing deep liar-count proof.

**31-MR-PROB (confirmed interface omission; mathematical implication itself valid).** The module header asserts a uniform random base error ≤1/4 and s independent rounds error ≤4^−s. The only probability-facing theorem found is `strongLiars_nat_card_le` at 2034. Repository search for `millerRabin`, `strongLiars_nat_card_le`, and probability companions finds no uniform product sample, acceptance-event cardinality, or final expectation/probability theorem for `millerRabinLoop`. The loop accepts an arbitrary deterministic list. For every odd composite n, base 1 is a strong liar, so an adversarial list of s copies of 1 passes with certainty; a distribution assumption really is required. Fix: define the uniform space `Fin s → Fin (n−1)`, convert to base list by +1, prove its loop-acceptance event factors, then apply the cardinality theorem. Alternatively explicitly describe the formal result as the one-base counting foundation and the repeated-round statement as an informal corollary. This does not refute the standard mathematical independence argument.
