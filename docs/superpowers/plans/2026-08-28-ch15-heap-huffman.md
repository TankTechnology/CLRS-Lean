# Chapter 15 Verified Heap Huffman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement an array binary-min-heap Huffman program whose exact result refines `huffmanOfFreqs` and whose attached work is bounded by `O(n log n)`.

**Architecture:** Decorate trees with distinct stable stamps and compare the lexicographic priority `(rootFreq tree, stamp)`.  Implement append/bubble-up and root-swap/pop/bubble-down on list-backed arrays, prove the heap invariant and permutation laws, observe heaps through priority insertion sort, and use the stable stamps to refine the existing sorted-list Huffman execution exactly.

**Tech Stack:** Lean 4, Mathlib list/permutation/order libraries, existing `CLRS.HuffmanV2` semantics, and Chapter 6 parent/left/right index arithmetic.

### Task 2: Stable heap entries

- [x] **Step 1: Define the entry and priority API**

```lean
structure HeapEntry where
  tree : HuffTree
  stamp : Nat
  deriving Repr, DecidableEq

def HeapEntry.priority (e : HeapEntry) : Nat × Nat :=
  (rootFreq e.tree, e.stamp)

def HeapEntry.le (a b : HeapEntry) : Prop := a.priority ≤ b.priority
def HeapEntry.lt (a b : HeapEntry) : Prop := a.priority < b.priority

def initialEntries (ts : List HuffTree) : List HeapEntry :=
  ts.zipWithIndex.map fun p => { tree := p.1, stamp := ts.length + p.2 }

def mergedEntry (queueSize : Nat) (a b : HeapEntry) : HeapEntry :=
  { tree := unite a.tree b.tree, stamp := queueSize - 2 }
```
