# 3D-IC Affine Strip Tightness Design

Date: 2026-08-30

Status: implemented, verified, and independently reviewed

## Goal

Strengthen the existing phase-aware affine-strip upper certificate into an
exact physical-load theorem on full period-aligned rectangles.  The result
must identify the assumptions that make equality true instead of describing
an upper bound as universally tight.

## Mathematical scope

For affine color

```text
color(i,j) = (alpha*i + beta*j + gamma) mod K,
```

write

```text
a = affineDirectionStep alpha beta along
b = affineDirectionStep alpha beta across
g = gcd(K,a)
T = K/g
R = g/gcd(g,b).
```

The existing theorem bounds the number of distinct physical color-`c` strip
points by `ceil(W/R) * ceil(L/T)`.  Equality is not valid without further
conditions: partial periods create phase-sensitive boundary effects, not all
colors need be generated by the two direction steps, and coincident samples
are removed by the physical-point semantics.

The exact theorem therefore assumes:

1. `0 < K` and `c < K`;
2. `gcd(gcd(K,a),b) = 1`, so the two strip steps generate every residue;
3. `R ∣ W` and `T ∣ L`, so the index rectangle contains complete phase cells;
4. the map `(r,t) ↦ stripPoint base along across r t` is injective on
   `r < W`, `t < L`.

Under these conditions every color occurs exactly once in each `R x T`
fundamental phase cell, and the physical load is

```text
(W / R) * (L / T)
  = ceil(W / R) * ceil(L / T).
```

The statement includes zero-width and zero-length strips.  Their injectivity
condition is vacuous and both sides are zero.  The positivity of `K` makes
`R` and `T` positive.

## File structure

### `CLRSLean/Research/ThreeDIC/AffineStripTightnessCore.lean`

This file owns index-space arithmetic only:

- a public predicate for the full-color-period condition;
- a public `R x T` fundamental-cell color map;
- the period-product theorem `R * T = K` under the full-period condition;
- injectivity and bijectivity of the fundamental-cell map;
- exact color-index counting for period-aligned `W x L` rectangles.

It must not mention physical-point deduplication or finite-grid placement.

### `CLRSLean/Research/ThreeDIC/AffineStripTightness.lean`

This file owns the physical bridge:

- `affineStripSamplingInjective`, expressed on the finite strip index domain;
- equality between physical color-point cardinality and color-index
  cardinality under that predicate;
- the general exact-load theorem;
- a wrapper whose right-hand side is syntactically identical to the existing
  phase-aware upper bound;
- axis-aligned wrappers that discharge physical injectivity automatically;
- fixed-color horizontal and vertical specializations.

No existing large production file will absorb the new proof.

## Intended public theorem surface

The exact spelling may change only to follow an unavoidable Lean namespace or
elaboration constraint; the logical interfaces are frozen as follows.

```lean
def affineStripFullColorPeriod
    (alpha beta K : Nat) (along across : Nat × Nat) : Prop

theorem affineStripPeriod_product_eq
    ... (hK : 0 < K) (hFull : affineStripFullColorPeriod ...) :
    affineStripAcrossPeriod alpha beta K along across *
      affineLinePeriod alpha beta K along = K

theorem affineStripColorIndexCount_eq_of_period_dvd
    ... (hK : 0 < K) (hc : c < K) (hFull : ...)
    (hRW : affineStripAcrossPeriod ... ∣ W)
    (hTL : affineLinePeriod ... ∣ L) :
    affineStripColorIndexCount ... =
      (W / affineStripAcrossPeriod ...) *
        (L / affineLinePeriod ...)

def affineStripSamplingInjective
    (W L : Nat) (base along across : Nat × Nat) : Prop

theorem affineStripColor_load_eq_of_period_dvd
    ... (hK : 0 < K) (hc : c < K) (hFull : ...)
    (hRW : affineStripAcrossPeriod ... ∣ W)
    (hTL : affineLinePeriod ... ∣ L)
    (hInjective : affineStripSamplingInjective W L base along across) :
    (affineStripColorPoints ...).card =
      (W / affineStripAcrossPeriod ...) *
        (L / affineLinePeriod ...)

theorem affineStripColor_load_eq_phase_periods
    ... same hypotheses ... :
    (affineStripColorPoints ...).card =
      ((W + affineStripAcrossPeriod ... - 1) /
        affineStripAcrossPeriod ...) *
      ((L + affineLinePeriod ... - 1) /
        affineLinePeriod ...)
```

Axis-aligned wrappers specialize `along = (1,0)` and `across = (0,1)`, or the
swapped orientation.  They may use the simpler sufficient assumption that at
least one affine coefficient is coprime to `K`.  Fixed-color wrappers
specialize to `(alpha,beta,gamma) = (1,M,0)`.

## Proof architecture

1. Normalize strip colors to the modular expression `A + b*r + a*t`.
2. Reuse or restate the existing congruence argument: equal colors imply
   equal row residues modulo `R`; inside one row they imply equal along
   residues modulo `T`.
3. On `Fin R × Fin T`, residue equality becomes ordinary equality, so the
   fundamental-cell color map is injective.
4. Prove `R*T = K` from `gcd(g,b)=1`; finite injectivity between equally sized
   types yields surjectivity and exactly one preimage for each `c < K`.
5. Decompose `r < W` and `t < L` into quotient and remainder coordinates.
   Divisibility of `W` by `R` and `L` by `T` makes every quotient block full.
6. Map every color index to its quotient block.  Fundamental-cell bijectivity
   supplies exactly one color index in every block, giving exact index count.
7. Under `affineStripSamplingInjective`, the existing image-based physical
   representation preserves cardinality, lifting index equality to distinct
   physical points.
8. Rewrite exact quotients as the ceiling expressions used by the upper
   certificate.

The proof must not enumerate coefficient values or use `native_decide` for a
general theorem.

## Boundaries and counterexamples

- If the full-period condition fails, only a proper residue coset may occur;
  an all-colors exact statement is false.
- If `R` does not divide `W` or `T` does not divide `L`, boundary phases can
  make different valid colors receive different floor/ceiling loads.
- If physical sampling is not injective, distinct index witnesses may name
  the same bump and are intentionally deduplicated.
- The theorem does not imply a simple repair-chain ordering, bounded routing
  length, spare reachability, mux feasibility, or repair success.

One executable regression example will use coincident directions to show that
removing the injectivity hypothesis would make the physical equality false.

## Claim boundary

Allowed: the phase-aware certificate is exact for full-period, period-aligned,
non-self-overlapping affine strips, with verified axis-aligned corollaries.

Forbidden: the upper bound is always tight; arbitrary partial strips have the
same exact count; the theorem proves DART repairability or solves the overall
3D-IC repair problem.
